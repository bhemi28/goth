info Project Overview

An event asset selection and client onboarding platform for ShowEngine, transforming their offline event organization workflow into a streamlined digital experience. The system provides a comprehensive web-based asset library where clients can browse and customize event setups including tents, decorations, and other event materials.

Replaced traditional on-premise workflows with a fully online system, enabling efficient client onboarding, asset management, and event resource allocation. Integrated AI-powered image categorization and automated tag generation to streamline asset organization and improve searchability across the platform.
