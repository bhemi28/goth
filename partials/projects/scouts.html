info Project Overview

A comprehensive admin panel built for Scouts Canada to manage group leaders, member groups, seasonal fundraising campaigns, and product catalogs. The system streamlined their fundraising workflow with order management and tracking capabilities, replacing manual processes with an automated digital solution.

On this backend-heavy project, I took ownership of most API development tasks while my teammate focused on higher-priority initiatives. Collaborated closely with the Shopify UI team and provided comprehensive post-launch support for production issues.

engineering Technical Implementation

MongoDB Schema Design

Designed complex relational models within MongoDB linking groups, leaders, campaigns, and products with proper indexing for performance optimization.

Dynamic Aggregation Pipelines

Built complex MongoDB aggregation pipelines for listing groups/products with dynamic filters, search functionality, and efficient sorting mechanisms.

API Architecture & Validation

Developed robust REST APIs with comprehensive field validation, data consistency checks, and proper error handling for production reliability.

Fundraising Campaign Management

Implemented campaign lifecycle management with state transitions, order tracking, and automated workflow processes for seasonal fundraising cycles.
