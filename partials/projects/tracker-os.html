info Project Overview

"Tracker OS" is a comprehensive job application tracker built to replace cumbersome spreadsheets. It offers a high-density dashboard to efficiently view, manage, and track applications through the entire hiring pipeline—from initial application to the final offer.

The core goal is to create a "sheet killer" for job seekers, providing a superior user experience with features like quick-add forms, status tracking, and persistent storage.

engineering Technical Implementation

Full-Stack Architecture

Built with a React frontend and a NestJS backend, ensuring a scalable and maintainable codebase.

State Management & Forms

Leverages Redux Toolkit (RTK Query) for efficient data fetching and caching, and React Hook Form for robust form handling.

Database & Persistence

Uses MongoDB with Mongoose for flexible data storage, all running inside a Docker container with volumes for data persistence.

User Experience

Features include a dynamic dashboard with both table and tile views, a quick-add modal for new applications, and instant search/filtering capabilities.
