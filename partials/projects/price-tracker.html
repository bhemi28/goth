info Project Overview

A backend service designed to track price and availability changes across multiple e-commerce platforms. The system performs periodic data ingestion, stores historical pricing data, and provides APIs for querying price trends and availability status.

Built with Go for high-performance concurrent processing and MongoDB for flexible document storage of product data with varying schemas across different platforms.

engineering Technical Implementation

Data Ingestion Pipeline

Concurrent workers scraping product data with configurable intervals, rate limiting, and retry mechanisms for handling platform-specific challenges.

Price Change Detection

Algorithm for detecting meaningful price changes while filtering noise, with configurable thresholds and trend analysis.

REST API Layer

Clean API endpoints for product search, price history, and real-time availability with proper pagination and filtering.
